# fabric_items_endpoint/

โฟลเดอร์นี้ผูกกับ workspace `ws-dataops-dev-endpoint-<ชื่อ>` ผ่าน Fabric Git integration (branch `dev`, Git folder `/fabric_items_endpoint`) — Lakehouse `lh_endpoint_lab` ที่คุณสร้างใน Fabric UI แล้วกด Commit จะมาอยู่ที่นี่ (Lab 0 ขั้น 5)

CI (`scripts/deploy_endpoints.py` ผ่าน `endpoint-targets.yml`) จะเอา item ในโฟลเดอร์นี้ไป deploy ที่ prod-endpoint (Lab 0 ขั้น 6)

**ห้ามเขียนไฟล์ item มือเข้ามาที่นี่** — สร้างผ่าน Fabric UI แล้ว Commit เท่านั้น
